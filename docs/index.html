A language that compiles to WasmGC.

The compiler, standard library, parser, and analysis engine ship as one bundle. It is the same bytes in Node, Bun, a browser, an IDE, or CI. There is no separate stdlib install, no host-specific build, and no lite version.

Wutu, utu's built-in DOM and CSS language. Markup, styles, and events in one typed expression. This page is written in it.

TypeScript declarations are the foreign-function interface.

std:Browser gives typed access to the whole DOM and JavaScript standard library, and any npm package with types imports directly. Only the boundary operations a program uses are emitted.

using Browser from std:Browser;
using Nano from "npm:nanoid";

export main() void {
    let item = Browser.document.createElement("li");
    item.textContent = Nano.nanoid(8);
    Browser.document.body.append(item);
}
JavaScript, the browser, and npm

Iterators are syntax, and they fuse.

A pipeline over a native array compiles to one Wasm loop with scalar locals. No iterator objects, no closures, no operator library, no intermediate collections.

export main() I32 {
    [1, 2, 3, 4, 5]
        map |n| { n * 2; }
        filter |n| { n > 4; }
        fold (0) |total, n| { total + n; };
}
