# Examples

Run any standalone example with the CLI:

```sh
./cli/utu.mjs examples/hello.utu
```

## Starting points

- [working/](working/README.md) — minimal verified examples (`hello`, `arrays_and_for`, `structs`, `strings`, `closures`)
- `hello.utu`, `closures.utu`, `protocols.utu`, `results.utu`, `promises.utu`, `streams.utu`, `templates.utu`, `stdlib.utu`, `wat.utu` — language and stdlib demos
- `json/`, `queries/`, `modules/`, `multi_file/` — typed JSON, range/spatial indexes, and multi-file modules

## Browser & Wutu apps

- [browser-board/](browser-board/README.md) — task board built with `std:Browser`
- [browser-pantry/](browser-pantry/README.md) — dashboard built with `std:Browser`
- [wutu-garden/](wutu-garden/README.md) — plant-care app built with Wutu
- [wutu-five/](wutu-five/README.md) — five complete Wutu websites (`folio`, `juniper`, `wayfarer`, `signal`, `scope`)
- `wutu-reactive/`, `wutu-components/`, `wutu-more/`, `wutu-round-one/`, `wutu-round-two/` — additional Wutu apps and reactive views

## Test & diagnostic corpora

- [error_demo/](error_demo/README.md) — intentionally invalid programs for diagnostic and blame-chain testing
- `ci/`, `wutu-regressions/` — compiler and Wutu regression fixtures
