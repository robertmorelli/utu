# utu skill for Claude Code

`writing-utu/SKILL.md` teaches an agent idiomatic utu and Wutu: tagged data, nullables, pipelines, interop, Wutu markup and CSS rules, the CLI, and the common mistakes with what the compiler says. Agents load it before writing or reviewing `.utu` code.

```sh
ln -s "$PWD/editors/skill/writing-utu" ~/.claude/skills/writing-utu                  # every project
ln -s "$PWD/editors/skill/writing-utu" /path/to/project/.claude/skills/writing-utu   # one project
```

Run from this repository. A link keeps the skill current with the checkout. The skill names docs by their path here (`docs/language/…`).
